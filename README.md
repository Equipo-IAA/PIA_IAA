# Predicción del retorno de clientes mediante Random Forest

## Objetivo
Utilizar información histórica de transacciones para identificar patrones de compra y desarrollar un modelo de clasificación mediante Random Forest.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook


## Resultados principales

El modelo Random Forest obtuvo los siguientes resultados promedio en diez experimentos:

| Métrica   | Resultado |
|-----------|-----------|
| Accuracy  | 70.40 %   |
| Precision | 73.11 %   |
| Recall    | 69.54 %   |
| F1-Score  | 71.26 %   |
| ROC-AUC   | 77.57 %   |
